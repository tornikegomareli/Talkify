- Added Dictate and Translate. Choose a language in Settings > Language, hold the Translate key, speak in your own language, and the translation lands in the document. The key stays the same when you change the language, and the notch shows the pair before you start talking.
- Added translation to Read Aloud. Turn on Translate before speaking in Settings > Read Aloud, select text in a language you do not read, and hear it in your voice's language. The voice is the target, so there is nothing else to set.
- Translation runs on your Mac through Apple's Translation framework. Nothing you say or select is sent anywhere. English translates to eleven languages with nothing to download; a few others fetch a model once, from Settings.
- A translated dictation session keeps both languages in transcription history, and Insights counts the words you spoke rather than the words that were inserted.
- If a translation fails, nothing is pasted and your words go to the clipboard.
- Fixed Read Aloud finding nothing to read. Asking macOS 26 which element has focus returns nothing at all, for every application, so Read Aloud said "No text selected" whatever was selected. It asks the frontmost application now.
- Read Aloud now works on web pages. No browser reports its selection, so the selection is read by copying it, and your clipboard is put back afterwards.

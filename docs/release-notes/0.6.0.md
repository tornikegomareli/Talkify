- Added transcription history. Off by default. One plain text file per day in a folder you choose, and each entry names the app the text went to, with the transcription and its date.
- History is written before the paste, so a failed paste or a crashed app never loses the sentence.
- Added a choice of where finished text goes: insert into the app, copy to the clipboard, or both.
- Added an option to lower other audio while dictating and restore it after. If you move the volume yourself mid-sentence, your setting is kept.
- Fixed Read Aloud reading selections from secure password fields out loud.
- Fixed the last sentence being dropped when quitting while dictation was still finishing.
- Fixed file transcripts being left readable in the temp folder after a crash. They are swept at launch and written owner only.
- Hardened Accessibility interop against unexpected values from other apps.

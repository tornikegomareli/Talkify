- Dictated text no longer turns up in clipboard manager history. Insertion works by pasting, so every phrase passed through the clipboard for about half a second and Paste, Raycast and Alfred recorded it as an ordinary copy. That write is now marked transient and auto-generated, which those apps honour. Copy to the clipboard and insert and copy are unchanged: text you asked to keep is an ordinary copy.
- On a display with no notch the HUD sits where a notch would be again, rather than hanging below the menu bar. A new Appearance setting, Clear the menu bar on other displays, puts it back below for a menu bar crowded enough that the shape reaches your status icons.
